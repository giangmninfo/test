CSS Syntax — Cú pháp CSS

Cấp độ: Cơ bản Cập nhật: 16/06/2026 275K lượt đọc

Cú pháp CSS (CSS Syntax) là tập hợp các quy tắc xác định cách viết mã CSS để trình duyệt hiểu và áp dụng kiểu cho trang web. Mỗi quy tắc CSS (rule set) gồm một bộ chọn (selector) và một khối khai báo (declaration block) đặt trong cặp dấu ngoặc nhọn { }.

Ghi nhớ: Một quy tắc CSS có dạng: selector { property: value; }

Các thành phần của một quy tắc CSS

  • Selector (bộ chọn): chỉ ra phần tử HTML sẽ được áp dụng kiểu.
  • Declaration block (khối khai báo): nằm trong { }, chứa một hoặc nhiều khai báo.
  • Declaration (khai báo): một cặp property: value.
  • Property (thuộc tính): đặc điểm muốn thay đổi, ví dụ color.
  • Value (giá trị): giá trị gán cho thuộc tính, ví dụ red.
  • Mỗi khai báo kết thúc bằng dấu chấm phẩy ;, ngăn cách các khai báo với nhau.

Ví dụ & giải thích

h1 {
  color: blue;
  font-size: 24px;
}

Trong ví dụ trên:

  • h1 là selector — chọn tất cả thẻ <h1>.
  • { ... } là declaration block.
  • color: blue; và font-size: 24px; là hai declaration.
  • color, font-size là property; blue, 24px là value.

Các loại bộ chọn thường gặp

LoạiCú phápÝ nghĩa
Elementp { }Chọn mọi thẻ <p>.
ID#main { }Chọn phần tử có id="main" (duy nhất).
Class.note { }Chọn mọi phần tử có class="note".
Grouph1, h2, p { }Áp dụng cùng kiểu cho nhiều selector.
Universal* { }Chọn tất cả phần tử.
Descendantdiv p { }Chọn <p> nằm trong <div>.
Attributeinput[type="text"] { }Chọn theo thuộc tính.

Chú thích trong CSS

Chú thích giúp giải thích mã và bị trình duyệt bỏ qua. Dùng cú pháp /* ... */:

/* Đây là một chú thích CSS */
p {
  color: green; /* màu chữ xanh lá */
}

Tóm tắt

Cú pháp CSS xoay quanh công thức selector { property: value; }. Hiểu rõ các thành phần — selector, declaration block, property, value — và các loại bộ chọn cơ bản sẽ giúp bạn viết CSS chính xác. Đừng quên dùng dấu ; sau mỗi khai báo và /* */ để ghi chú.
