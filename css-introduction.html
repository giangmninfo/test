CSS Introduction — Giới thiệu CSS

Cấp độ: Cơ bản Cập nhật: 16/06/2026 300K lượt đọc

CSS (Cascading Style Sheets) là ngôn ngữ dùng để trình bày và tạo kiểu cho tài liệu HTML. Nếu HTML quyết định cấu trúc và nội dung của trang, thì CSS quyết định diện mạo — màu sắc, phông chữ, khoảng cách, bố cục và hiệu ứng. Nhờ CSS, ta có thể tách biệt nội dung (HTML) khỏi phần trình bày, giúp mã gọn gàng và dễ bảo trì hơn.

Cascading (xếp tầng) nghĩa là khi nhiều quy tắc cùng áp dụng cho một phần tử, trình duyệt sẽ quyết định quy tắc nào thắng dựa trên độ ưu tiên (specificity) và thứ tự khai báo.

Tại sao nên dùng CSS?

  • Tách nội dung khỏi trình bày: HTML lo cấu trúc, CSS lo giao diện.
  • Tái sử dụng: Một file CSS có thể áp dụng cho nhiều trang cùng lúc.
  • Dễ bảo trì: Đổi giao diện cả website chỉ bằng cách sửa một nơi.
  • Responsive: Giúp trang hiển thị đẹp trên mọi kích thước màn hình.
  • Tải nhanh hơn: Giảm lặp mã, trình duyệt cache file CSS dùng chung.

Cú pháp CSS

Một quy tắc CSS gồm bộ chọn (selector) và khối khai báo:

selector {
  property: value;   /* một khai báo */
  property: value;
}

/* Ví dụ cụ thể */
h1 {
  color: blue;
  font-size: 24px;
}
  • Selector: chọn phần tử HTML cần tạo kiểu (ví dụ h1).
  • Property: thuộc tính muốn thay đổi (ví dụ color).
  • Value: giá trị áp dụng (ví dụ blue).
  • Mỗi khai báo kết thúc bằng dấu chấm phẩy ;.

Ba cách chèn CSS vào trang

1. Inline CSS — trực tiếp trên phần tử

Dùng thuộc tính style ngay trong thẻ. Chỉ nên dùng cho trường hợp đặc biệt.

<p style="color: red; font-size: 18px;">Đoạn văn màu đỏ</p>

2. Internal CSS — trong thẻ <style>

Đặt trong <style> ở phần <head>, áp dụng cho cả trang đó.

<head>
  <style>
    p { color: green; }
  </style>
</head>

3. External CSS — file .css riêng

Cách phổ biến nhất: viết CSS ở file riêng rồi liên kết bằng thẻ <link>.

<head>
  <link rel="stylesheet" href="styles.css">
</head>
Khuyến nghị: Dùng External CSS cho dự án thực tế vì dễ tái sử dụng và bảo trì — giống như chính trang web HITech này đang dùng chung một file styles.css.

Tóm tắt

CSS là ngôn ngữ tạo kiểu cho web, làm việc cùng HTML để tạo nên giao diện trang. Một quy tắc CSS gồm selector và các cặp property: value. Có ba cách chèn CSS — inline, internal và external — trong đó external CSS được khuyên dùng nhất. Nắm vững cú pháp và các bộ chọn cơ bản là bước khởi đầu để làm chủ thiết kế giao diện web.

Bước tiếp theo: Tìm hiểu về Box Model, màu sắc & đơn vị, và Flexbox/Grid để dựng bố cục trang.
