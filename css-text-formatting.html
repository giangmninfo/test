CSS Text Formatting — Định dạng văn bản với CSS

Cấp độ: Cơ bản Cập nhật: 17/06/2026 274K lượt đọc

CSS Text Formatting là tập hợp các thuộc tính giúp định dạng và trình bày văn bản trên trang web: đổi màu chữ, căn lề, gạch chân, viết hoa/thường, giãn dòng, khoảng cách ký tự, bóng chữ… Nhờ đó nội dung trở nên dễ đọc và đẹp mắt hơn.

Lưu ý: Các thuộc tính định dạng văn bản (text-*) khác với thuộc tính font (font-family, font-size, font-weight…). Trang này tập trung vào nhóm text-* và khoảng cách.

Màu chữ — color

Đặt màu cho văn bản bằng tên màu, HEX, RGB hoặc HSL:

p { color: #2da44e; }

Tóm tắt

CSS cung cấp nhiều thuộc tính để định dạng văn bản: color (màu), text-align (căn lề), text-decoration (gạch chân/ngang), text-transform (hoa/thường), text-indent (thụt đầu dòng), letter-spacing/word-spacing (khoảng cách), line-height (chiều cao dòng) và text-shadow (bóng chữ). Kết hợp khéo léo giúp văn bản dễ đọc và hấp dẫn hơn.

Bước tiếp theo: Xem CSS Colors để tô màu chữ và CSS Borders để trang trí khối văn bản.
