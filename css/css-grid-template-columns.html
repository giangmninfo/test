CSS grid-template-columns — Định nghĩa cột lưới

Cấp độ: Cơ bản Cập nhật: 22/06/2026 228K lượt đọc

grid-template-columns định nghĩa số cột và bề rộng mỗi cột của một grid container. Mỗi giá trị là bề rộng một cột; số giá trị quyết định số cột.

Đơn vị thường dùng: px/% (cố định), fr (phần chia), cùng các hàm repeat(), minmax() và từ khóa auto-fit/auto-fill.

Thực hành tốt

  • Ưu tiên fr + repeat() cho cột co giãn, code gọn.
  • Dùng minmax() để cột không bị quá hẹp.
  • repeat(auto-fit, minmax(...,1fr)) = lưới responsive tự động.
  • Dùng grid-template-rows tương tự để định nghĩa hàng.

Tóm tắt
