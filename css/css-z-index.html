CSS z-index — Thứ tự xếp chồng

Cấp độ: Cơ bản Cập nhật: 22/06/2026 201K lượt đọc

z-index quy định thứ tự xếp chồng (theo trục z — chiều sâu) của các phần tử bị chồng lên nhau: giá trị càng lớn càng nằm trên.

Điều kiện: z-index chỉ có tác dụng khi phần tử có position khác static (tức relative, absolute, fixed hoặc sticky).

Giá trị âm

z-index âm đẩy phần tử ra phía sau (xuống dưới các phần tử khác):

Stacking context (ngữ cảnh xếp chồng)

Mỗi phần tử có position + z-index (hoặc opacity < 1, transform…) tạo một ngữ cảnh xếp chồng riêng. z-index của con chỉ so sánh trong cùng ngữ cảnh cha:

Thực hành tốt

  • Nhớ đặt position (thường relative) thì z-index mới có tác dụng.
  • Dùng thang giá trị hợp lý (vd 10, 100, 1000) thay vì 9999 lung tung.
  • Hiểu stacking context để tránh "z-index cao mà vẫn bị che".
  • Hạn chế lạm dụng z-index lớn — dễ gây xung đột khó debug.

Tóm tắt

z-index quyết định thứ tự xếp chồng theo chiều sâu — giá trị lớn hơn nằm trên. Chỉ có tác dụng khi phần tử có position khác static. Giá trị âm đẩy ra sau; cần hiểu stacking context vì z-index của con chỉ so trong cùng ngữ cảnh cha.

Bước tiếp theo: Xem lại CSS Display và CSS Float & Clear để hoàn thiện nhóm bố cục.
