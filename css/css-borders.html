CSS Borders

Cấp độ: Cơ bản Cập nhật: 16/06/2026 230K lượt đọc

Border (viền) trong CSS là đường bao quanh nội dung và phần đệm (padding) của một phần tử. Viền giúp phân tách, làm nổi bật hoặc trang trí các khối. Một viền được xác định bởi ba yếu tố: kiểu (style), độ dày (width) và màu (color).

Quan trọng: Phải có border-style thì viền mới hiển thị — chỉ đặt border-width hay border-color mà thiếu style sẽ không thấy gì.

Các thuộc tính border

Thuộc tínhCông dụng
border-styleKiểu viền (solid, dashed...).
border-widthĐộ dày viền.
border-colorMàu viền.
border-top/right/bottom/leftViền cho từng cạnh.
borderThuộc tính rút gọn.
border-radiusBo tròn góc.

1. border-style

Xác định kiểu đường viền. Các giá trị thường dùng: solid, dashed, dotted, double, groove, ridge, none.

2. border-width

Đặt độ dày viền bằng px (hoặc thin/medium/thick).

3. border-color

Đặt màu viền bằng tên màu, HEX, RGB, HSL...

4. Viền cho từng cạnh

Có thể đặt viền riêng cho từng cạnh với border-top, border-right, border-bottom, border-left.

5. Thuộc tính rút gọn (shorthand)

Gộp width, style, color vào một dòng border:

div {
  border: 2px solid #1a73e8;
  /* width style color */
}

6. border-radius (bo góc)

Bo tròn các góc của viền. Giá trị càng lớn càng tròn; 50% tạo hình tròn/elip.

Tóm tắt

Viền CSS gồm ba yếu tố: border-style, border-width và border-color — trong đó border-style là bắt buộc để viền hiển thị. Có thể đặt viền cho từng cạnh, gộp bằng thuộc tính rút gọn border, và bo góc bằng border-radius.

Bước tiếp theo: Tìm hiểu Box Model để hiểu mối quan hệ giữa content, padding, border và margin.
