CSS Selectors

Cấp độ: Cơ bản Cập nhật: 16/06/2026 290K lượt đọc

Bộ chọn CSS (CSS Selector) là phần của quy tắc CSS dùng để chỉ định phần tử HTML sẽ được áp dụng kiểu. Selector đứng trước khối khai báo { } và cho trình duyệt biết "tạo kiểu cho phần tử nào". Việc chọn đúng phần tử là kỹ năng nền tảng khi viết CSS.

Ghi nhớ: selector { property: value; } — phần selector chính là chủ đề của bài này.

Phân loại bộ chọn CSS

NhómVí dụMô tả
Cơ bản (simple)p, #id, .class, *Chọn theo tên thẻ, id, class hoặc tất cả.
Nhóm (grouping)h1, h2, pÁp dụng cùng kiểu cho nhiều selector.
Thuộc tính (attribute)input[type="text"]Chọn theo thuộc tính và giá trị.
Combinatordiv > pChọn theo quan hệ (xem bài CSS Combinators).
Pseudo-classa:hoverChọn theo trạng thái/vị trí.
Pseudo-elementp::first-lineChọn một phần của phần tử.

1. Bộ chọn cơ bản & nhóm

  • Element: p { } — chọn mọi thẻ <p>.
  • ID: #main { } — chọn phần tử có id="main" (duy nhất).
  • Class: .note { } — chọn mọi phần tử có class="note".
  • Universal: * { } — chọn tất cả phần tử.
  • Grouping: h1, h2, p { } — áp dụng chung cho nhiều selector.

2. Combinator Selectors

Combinator chọn phần tử dựa trên mối quan hệ với phần tử khác trong cây HTML. CSS có 4 combinator:

CombinatorKý hiệuChọn...
Descendant(dấu cách)mọi con cháu bên trong (mọi cấp).
Child>con trực tiếp.
Adjacent sibling+phần tử cùng cấp đứng ngay sau.
General sibling~mọi phần tử cùng cấp đứng sau.

3. Bộ chọn thuộc tính (Attribute)

Chọn phần tử dựa trên thuộc tính và/hoặc giá trị của thuộc tính.

Cú phápChọn phần tử...
[title]có thuộc tính title.
[type="text"]có type đúng bằng "text".
[class~="box"]có giá trị chứa từ "box".
[href^="https"]có giá trị bắt đầu bằng "https".
[href$=".pdf"]có giá trị kết thúc bằng ".pdf".
[href*="hitech"]có giá trị chứa "hitech".

4. Pseudo-class

Pseudo-class chọn phần tử theo trạng thái hoặc vị trí đặc biệt, viết sau dấu hai chấm :.

  • :hover — khi rê chuột lên.
  • :focus — khi phần tử được focus.
  • :first-child / :last-child — con đầu/cuối.
  • :nth-child(n) — con thứ n.

5. Pseudo-element

Pseudo-element chọn một phần của phần tử, viết sau hai dấu hai chấm ::.

  • ::first-line — dòng đầu tiên.
  • ::first-letter — chữ cái đầu tiên.
  • ::before / ::after — chèn nội dung trước/sau.
  • ::selection — phần văn bản được bôi đen.

Tóm tắt

Bộ chọn CSS quyết định phần tử nào được tạo kiểu. Các nhóm chính gồm: bộ chọn cơ bản (element, id, class, universal), nhóm, thuộc tính, combinator, pseudo-class và pseudo-element. Kết hợp linh hoạt các loại selector giúp bạn nhắm đúng phần tử mà không cần thêm class thừa.

Bước tiếp theo: Xem lại bài CSS Combinators và tìm hiểu về độ ưu tiên (specificity) khi nhiều selector cùng áp dụng.
