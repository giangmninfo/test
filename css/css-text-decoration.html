CSS text-decoration — Gạch chân & trang trí chữ

Cấp độ: Cơ bản Cập nhật: 22/06/2026 187K lượt đọc

text-decoration thêm đường kẻ trang trí cho chữ: gạch chân, gạch trên, gạch ngang — kèm tùy chọn màu, kiểu nét và độ dày. Đây là thuộc tính rút gọn của text-decoration-line/color/style/thickness.

Mẹo: Dùng text-decoration: none để bỏ gạch chân mặc định của liên kết <a>.

Đường kẻ — text-decoration-line

underline, overline, line-through, none:

Màu đường kẻ — text-decoration-color

Kiểu đường kẻ — text-decoration-style

solid, double, dotted, dashed, wavy:

Độ dày — text-decoration-thickness

Thuộc tính rút gọn

Gộp: text-decoration: line color style thickness:

Bỏ gạch chân liên kết

Dùng text-decoration: none (thường kết hợp gạch chân khi hover):

Thực hành tốt

  • Giữ liên kết dễ nhận biết: nếu bỏ gạch chân, hãy có dấu hiệu khác (màu, hover).
  • Dùng line-through cho nội dung đã xóa/giá cũ.
  • Dùng thuộc tính rút gọn để đặt màu/kiểu/độ dày cùng lúc.
