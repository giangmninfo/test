CSS Colors

Cấp độ: Cơ bản Cập nhật: 16/06/2026 260K lượt đọc

Màu sắc là một phần quan trọng trong thiết kế web. CSS cho phép bạn đặt màu cho chữ, nền, viền và nhiều thành phần khác bằng nhiều định dạng màu khác nhau: tên màu, HEX, RGB/RGBA và HSL/HSLA. Hiểu các định dạng này giúp bạn kiểm soát chính xác màu sắc và độ trong suốt.

Ghi nhớ: Các thuộc tính màu phổ biến gồm color (màu chữ), background-color (màu nền) và border-color (màu viền).

Áp dụng màu ở đâu?

p {
  color: blue;              /* màu chữ */
  background-color: #f0f0f0; /* màu nền */
  border: 2px solid red;     /* màu viền */
}

1. Tên màu (Named colors)

CSS hỗ trợ khoảng 140 tên màu có sẵn như red, green, tomato, steelblue.

2. Màu HEX

Dạng #RRGGBB — mỗi cặp ký tự (00–FF) biểu diễn cường độ đỏ, lục, lam. Có thể viết tắt 3 ký tự #RGB (ví dụ #1a7).

3. RGB & RGBA

rgb(r, g, b) với mỗi giá trị 0–255. rgba() thêm kênh alpha (0 = trong suốt, 1 = đục) để tạo độ mờ.

4. HSL & HSLA

hsl(hue, saturation, lightness): hue (0–360 độ trên vòng màu), saturation (% bão hòa), lightness (% độ sáng). hsla() thêm alpha. HSL trực quan khi cần chỉnh sắc độ/độ sáng.

Tóm tắt

CSS cho phép khai báo màu bằng tên, HEX, RGB/RGBA và HSL/HSLA. HEX và RGB phổ biến nhất; RGBA và HSLA hỗ trợ độ trong suốt; HSL trực quan khi điều chỉnh sắc độ và độ sáng. Áp dụng màu qua các thuộc tính như color, background-color và border-color.

Bước tiếp theo: Tìm hiểu về background (gradient, hình nền) và đơn vị trong CSS.

Khóa học CSS

Làm chủ màu sắc, typography và bố cục để thiết kế web đẹp.
