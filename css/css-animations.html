CSS Animations — Hoạt ảnh với @keyframes

Cấp độ: Cơ bản Cập nhật: 22/06/2026 318K lượt đọc

CSS Animations cho phép tạo chuyển động phức tạp, tự chạy và lặp lại qua nhiều bước — khác với transition (chỉ giữa 2 trạng thái và cần kích hoạt). Animation định nghĩa các mốc bằng @keyframes rồi gắn vào phần tử.

Hai phần: (1) khai báo @keyframes tên { ... }; (2) áp dụng bằng animation trên phần tử.

@keyframes

Định nghĩa trạng thái tại các mốc (from/to hoặc %):

Thuộc tính animation

  • animation-name: tên @keyframes.
  • animation-duration: thời lượng một vòng.
  • animation-timing-function: kiểu easing.
  • animation-delay: độ trễ.
  • animation-iteration-count: số lần lặp (infinite = vô hạn).
  • animation-direction: normal, alternate…
  • animation-fill-mode: giữ trạng thái đầu/cuối.

Thuộc tính rút gọn

animation: name duration timing-function delay iteration-count direction;

Thực hành tốt

  • Dùng animation cho chuyển động tự chạy/lặp; transition cho tương tác 2 trạng thái.
  • Ưu tiên animate transform & opacity cho mượt.
  • animation-iteration-count: infinite cho loader/spinner.
  • Tôn trọng prefers-reduced-motion cho người nhạy cảm chuyển động.

Tóm tắt

CSS Animations tạo chuyển động tự chạy/lặp qua nhiều mốc: định nghĩa @keyframes rồi áp dụng bằng animation (name, duration, timing, delay, iteration-count, direction, fill-mode). Khác transition ở chỗ tự chạy, nhiều bước và lặp được.

Bước tiếp theo: Ôn lại CSS Transitions (2 trạng thái) và CSS Transform (biến đổi) để phối hợp hiệu ứng.
