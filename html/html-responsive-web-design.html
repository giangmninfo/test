HTML Responsive Web Design — Thiết kế web đáp ứng

Cấp độ: Trung bình Cập nhật: 17/06/2026 312K lượt đọc

Responsive Web Design (RWD) — thiết kế web đáp ứng — là cách xây dựng trang web sao cho giao diện tự điều chỉnh để hiển thị tốt trên mọi kích thước màn hình: điện thoại, máy tính bảng, laptop và màn hình lớn. Thay vì làm nhiều phiên bản riêng, ta dùng một bộ mã co giãn linh hoạt theo thiết bị.

Ba trụ cột của RWD: thẻ meta viewport, media queries và bố cục/đơn vị linh hoạt (phần trăm, Flexbox, Grid).

Vì sao cần responsive?

  • Phần lớn người dùng truy cập web bằng điện thoại.
  • Trải nghiệm tốt trên mọi thiết bị, không phải phóng to/cuộn ngang.
  • Chỉ cần một website duy nhất, dễ bảo trì.
  • Tốt cho SEO (Google ưu tiên trang thân thiện di động).

1. Thẻ meta viewport

Đây là dòng bắt buộc đầu tiên cho web responsive. Nó yêu cầu trình duyệt khớp chiều rộng trang với chiều rộng thiết bị: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">
  • width=device-width — đặt chiều rộng trang bằng chiều rộng màn hình.
  • initial-scale=1.0 — mức phóng to ban đầu là 100%.

2. Media queries

@media cho phép áp dụng CSS khác nhau theo kích thước màn hình (breakpoint). Ví dụ đổi màu nền và sắp xếp khi màn hình hẹp: 

/* Mặc định (màn hình lớn) */
.box { background: #2da44e; }

/* Khi rộng tối đa 600px (di động) */
@media (max-width: 600px) {
  .box { background: #0969da; }
}

4. Ảnh đáp ứng

Cho ảnh co theo khung mà không bị tràn bằng max-width:100% và height:auto: 

img { max-width: 100%; height: auto; }

Ngoài ra có thể dùng thuộc tính srcset để chọn ảnh theo độ phân giải, hoặc thẻ <picture> để đổi ảnh theo điều kiện màn hình.

Thực hành tốt

  • Luôn thêm thẻ meta viewport.
  • Thiết kế theo hướng mobile-first (mặc định cho di động, mở rộng dần lên).
  • Dùng đơn vị linh hoạt (%, rem, vw) thay vì px cứng.
  • Cho ảnh/video max-width:100% để không tràn.
  • Chọn breakpoint theo nội dung, không theo từng thiết bị cụ thể.
  • Kiểm thử trên nhiều kích thước màn hình thật.

Tóm tắt

Responsive Web Design giúp một website hiển thị tốt trên mọi thiết bị. Ba yếu tố cốt lõi là thẻ meta viewport, media queries (@media) và bố cục/đơn vị linh hoạt (phần trăm, rem, vw, Flexbox, Grid). Kết hợp với ảnh đáp ứng (max-width:100%) và tư duy mobile-first để có trải nghiệm tốt nhất.

Bước tiếp theo: Xem HTML Layout để dựng bố cục và HTML Images để làm ảnh đáp ứng.
