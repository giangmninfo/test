HTML Layout — Bố cục trang web

Cấp độ: Cơ bản Cập nhật: 17/06/2026 288K lượt đọc

Bố cục (layout) là cách sắp xếp các thành phần của trang web — như tiêu đề, menu, nội dung chính và chân trang — thành một cấu trúc rõ ràng, dễ nhìn. Một website thường được chia thành các khu vực: header (đầu trang), nav (điều hướng), main/section/article (nội dung), aside (cột bên) và footer (chân trang).

Lưu ý: HTML định nghĩa cấu trúc các khu vực; còn việc sắp đặt vị trí (cạnh nhau, theo lưới…) chủ yếu do CSS đảm nhận (Flexbox, Grid, float).

Một bố cục website điển hình gồm các khu vực sau:

Các phần tử bố cục

Phần tửVai trò
<header>Phần đầu trang/khu vực — logo, tiêu đề, menu.
<nav>Khu vực chứa liên kết điều hướng.
<main>Nội dung chính, duy nhất của trang.
<section>Một phần/chủ đề trong tài liệu.
<article>Nội dung độc lập (bài viết, tin tức).
<aside>Nội dung phụ (sidebar, quảng cáo).
<footer>Chân trang — bản quyền, liên hệ.
<div>Hộp chứa chung khi không có thẻ ngữ nghĩa phù hợp.

Bố cục bằng thẻ ngữ nghĩa

Dùng các thẻ ngữ nghĩa HTML5 giúp mã rõ ràng, tốt cho SEO và trợ năng hơn là dùng toàn <div>: 

<body>
  <header>Tiêu đề trang</header>
  <nav>Menu</nav>
  <main>
    <section>Nội dung chính</section>
    <aside>Cột bên</aside>
  </main>
  <footer>Chân trang</footer>
</body>

Các kỹ thuật bố cục

  • CSS Flexbox — sắp xếp theo một chiều (hàng hoặc cột), linh hoạt, phổ biến nhất.
  • CSS Grid — sắp xếp theo hai chiều (hàng và cột), mạnh cho bố cục tổng thể.
  • CSS Float — kỹ thuật cũ, cho phần tử "trôi" sang trái/phải.
  • Table — chỉ nên dùng cho dữ liệu bảng, không dùng để dàn trang.

Bố cục responsive

Bố cục responsive tự điều chỉnh theo kích thước màn hình. Dùng @media để đổi cách sắp xếp trên di động (ví dụ chuyển từ nhiều cột sang một cột): 

.container { display: flex; }

@media (max-width: 600px) {
  .container { flex-direction: column; }
}

Thực hành tốt

  • Ưu tiên thẻ ngữ nghĩa (header, nav, main, footer) thay vì chỉ dùng <div>.
  • Dùng Flexbox cho bố cục một chiều, Grid cho bố cục hai chiều.
  • Thiết kế responsive với @media để hợp mọi thiết bị.
  • Tránh dùng bảng (<table>) để dàn trang.
  • Giữ cấu trúc gọn gàng, đặt tên lớp (class) rõ ràng.

Tóm tắt

Bố cục trang web chia giao diện thành các khu vực như header, nav, main, section, article, aside và footer. HTML tạo cấu trúc, còn CSS sắp đặt vị trí qua Flexbox, Grid hoặc float. Kết hợp @media để có bố cục responsive thích ứng mọi thiết bị.

Bước tiếp theo: Xem Semantic Elements để hiểu sâu các thẻ bố cục và HTML Tables để trình bày dữ liệu.
