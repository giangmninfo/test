HTML Tables — Bảng trong HTML

Cấp độ: Cơ bản Cập nhật: 17/06/2026 412K lượt đọc

Bảng (table) dùng để trình bày dữ liệu dạng lưới gồm hàng và cột, ví dụ thời khóa biểu, bảng giá, bảng điểm… Bảng được tạo bằng thẻ <table>, mỗi hàng là <tr> (table row) và mỗi ô dữ liệu là <td> (table data).

Lưu ý: Bảng chỉ nên dùng cho dữ liệu dạng bảng, không nên dùng để dàn trang (layout). Dàn trang hãy dùng CSS (Flexbox/Grid).

Ví dụ cơ bản

Một bảng gồm hàng tiêu đề và hai hàng dữ liệu:

<table>
  <tr>
    <th>Tên</th>
    <th>Tuổi</th>
  </tr>
  <tr>
    <td>An</td>
    <td>20</td>
  </tr>
  <tr>
    <td>Bình</td>
    <td>22</td>
  </tr>
</table>

Các thẻ của bảng

ThẻÝ nghĩa
<table>Định nghĩa một bảng.
<tr>Table row — một hàng trong bảng.
<th>Table header — ô tiêu đề (in đậm, căn giữa).
<td>Table data — ô dữ liệu thông thường.
<caption>Tiêu đề/chú thích của bảng.
<thead>Nhóm hàng tiêu đề.
<tbody>Nhóm hàng nội dung chính.
<tfoot>Nhóm hàng chân bảng (tổng kết).

Ô tiêu đề <th>

Dùng <th> thay cho <td> ở hàng/cột tiêu đề. Mặc định chữ in đậm và căn giữa, đồng thời tốt hơn cho trợ năng (trình đọc màn hình):

Nhóm hàng: thead, tbody, tfoot

Giúp bảng có cấu trúc rõ ràng, dễ tạo kiểu và hỗ trợ in/cuộn phần thân riêng: 

<table>
  <thead>
    <tr><th>Sản phẩm</th><th>Giá</th></tr>
  </thead>
  <tbody>
    <tr><td>Bút</td><td>5.000</td></tr>
    <tr><td>Vở</td><td>10.000</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Tổng</td><td>15.000</td></tr>
  </tfoot>
</table>

Tô màu & viền bằng CSS

Mặc định bảng không có viền. Dùng CSS border và border-collapse để gộp viền, padding cho thoáng và tô màu xen kẽ hàng (nth-child): 

table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #ccc; padding: 8px; text-align: left; }
tr:nth-child(even) { background: #f2f2f2; }
th { background: #2da44e; color: #fff; }

Thực hành tốt

  • Chỉ dùng bảng cho dữ liệu dạng bảng, không dùng để dàn trang.
  • Dùng <th> cho ô tiêu đề để hỗ trợ trợ năng.
  • Nhóm bằng <thead>/<tbody>/<tfoot> cho bảng lớn.
  • Thêm <caption> mô tả nội dung bảng.
  • Dùng border-collapse: collapse để viền gọn gàng.
  • Cho bảng cuộn ngang trên di động bằng cách bọc trong thẻ có overflow-x:auto.

Tóm tắt

Bảng được tạo bằng <table> với các hàng <tr> chứa ô tiêu đề <th> và ô dữ liệu <td>. Có thể nhóm hàng bằng <thead>/<tbody>/<tfoot>, thêm <caption>, gộp ô bằng colspan/rowspan và tạo kiểu bằng CSS với border-collapse, padding cùng màu xen kẽ.

Bước tiếp theo: Xem CSS Borders để làm đẹp viền bảng và CSS Overflow để cho bảng cuộn ngang trên di động.
