HTML5 Introduction — Giới thiệu HTML5

Cấp độ: Cơ bản Cập nhật: 17/06/2026 356K lượt đọc

HTML5 là phiên bản thứ năm và là bản nâng cấp lớn của ngôn ngữ HTML (HyperText Markup Language) — ngôn ngữ chuẩn để xây dựng trang web. HTML5 bổ sung nhiều thẻ ngữ nghĩa, hỗ trợ âm thanh/video gốc, đồ họa canvas/SVG, lưu trữ phía trình duyệt và nhiều API mạnh mẽ — giúp tạo web hiện đại, đa phương tiện mà không cần plugin bên ngoài (như Flash).

Ghi nhớ: HTML5 được W3C hoàn thiện thành chuẩn khuyến nghị năm 2014 và hiện là nền tảng của hầu hết website hiện đại.

Vì sao có HTML5?

  • Hỗ trợ đa phương tiện (audio, video) ngay trong HTML, không cần Flash.
  • Thêm thẻ ngữ nghĩa giúp mã rõ ràng, tốt cho SEO và trợ năng.
  • Cung cấp API mới: Geolocation, Web Storage, Drag & Drop, Canvas…
  • Chạy tốt trên thiết bị di động, hỗ trợ ứng dụng web hiện đại.

Khai báo & cấu trúc tài liệu

HTML5 đơn giản hóa phần khai báo <!DOCTYPE> và bảng mã ký tự: 

<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Trang HTML5</title>
</head>
<body>
  <h1>Xin chào HTML5!</h1>
</body>
</html>

So với HTML4 (doctype dài dòng), HTML5 chỉ cần <!DOCTYPE html> và <meta charset="UTF-8">.

Tính năng nổi bật của HTML5

Tính năngMô tả
Thẻ ngữ nghĩa<header>, <nav>, <section>, <article>, <footer>…
Audio & Video<audio> và <video> nhúng đa phương tiện không cần plugin.
Canvas & SVGVẽ đồ họa 2D động (<canvas>) và vector (<svg>).
Form nâng caoInput mới: email, date, range, color…

Một số phần tử mới

  • Ngữ nghĩa/bố cục: <header>, <footer>, <nav>, <main>, <section>, <article>, <aside>, <figure>, <figcaption>.
  • Đa phương tiện: <audio>, <video>, <source>, <track>, <embed>.
  • Đồ họa: <canvas>, <svg>.
  • Khác: <mark>, <progress>, <meter>, <details>, <summary>, <time>, <datalist>.

Một số thẻ bị loại bỏ

HTML5 loại bỏ các thẻ chỉ phục vụ trình bày (nên dùng CSS thay thế):

<font>, <center>, <big>, <strike>, <tt>, <frame>, <frameset>, <acronym>…

Hỗ trợ trình duyệt

HTML5 được hỗ trợ rộng rãi trên mọi trình duyệt hiện đại: Chrome, Firefox, Safari, Edge, Opera. Với trình duyệt rất cũ, một số tính năng có thể cần polyfill (mã bổ sung).

Ưu điểm của HTML5

  • Hỗ trợ đa phương tiện gốc, không cần plugin.
  • Mã ngữ nghĩa rõ ràng, thân thiện SEO và trợ năng.
  • Nhiều API mạnh để xây ứng dụng web hiện đại.
  • Tương thích đa thiết bị, đặc biệt là di động.
  • Tương thích ngược tốt với mã HTML cũ.

Tóm tắt

HTML5 là phiên bản hiện đại của HTML với doctype gọn nhẹ, nhiều thẻ ngữ nghĩa, hỗ trợ audio/video và đồ họa canvas/SVG tích hợp, cùng các API như Web Storage, Geolocation, Drag & Drop. HTML5 loại bỏ các thẻ trình bày cũ, được mọi trình duyệt hiện đại hỗ trợ và là nền tảng của web ngày nay.
