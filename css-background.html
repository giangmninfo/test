CSS Background

Cấp độ: Cơ bản Cập nhật: 16/06/2026 240K lượt đọc

Các thuộc tính background trong CSS cho phép bạn thiết lập nền cho phần tử — gồm màu nền, hình nền, cách lặp, vị trí, kích thước và hiệu ứng cuộn. Nền giúp trang web sinh động và làm nổi bật nội dung.

Ghi nhớ: Có thể đặt từng thuộc tính riêng lẻ hoặc gộp lại bằng thuộc tính rút gọn background.

Các thuộc tính background

Thuộc tínhCông dụng
background-colorĐặt màu nền.
background-imageĐặt hình nền (hoặc gradient).
background-repeatCách lặp hình nền.
background-positionVị trí của hình nền.
background-sizeKích thước hình nền.
background-attachmentCố định hay cuộn theo trang.
backgroundThuộc tính rút gọn gộp tất cả.

1. background-color

Đặt màu nền bằng tên màu, HEX, RGB, HSL...

2. background-image

Đặt hình nền bằng url(...). Có thể dùng nhiều ảnh, ngăn nhau bằng dấu phẩy.

div {
  background-image: url("anh-nen.jpg");
}

3. background-repeat

Điều khiển cách lặp ảnh nền: repeat (mặc định), repeat-x, repeat-y, no-repeat.

4. background-position & background-size

background-position đặt vị trí (vd center, top right, 50% 50%). background-size đặt kích thước (vd cover, contain, 100px 80px).

5. background-attachment

scroll (cuộn cùng nội dung — mặc định), fixed (cố định khi cuộn), local (cuộn theo nội dung phần tử).

6. Thuộc tính rút gọn (shorthand)

Gộp nhiều thuộc tính vào một dòng background:

div {
  background: #e8f0fe url("anh.png") no-repeat center / cover;
  /* color image repeat position / size */
}

7. Gradient (chuyển màu)

Gradient là hình nền đặc biệt: linear-gradient() (tuyến tính) và radial-gradient() (tỏa tròn).

Tóm tắt

CSS cung cấp nhiều thuộc tính để tạo nền: background-color, background-image, background-repeat, background-position, background-size, background-attachment, cùng thuộc tính rút gọn background và các hàm gradient. Kết hợp linh hoạt giúp tạo giao diện hấp dẫn.

Bước tiếp theo: Tìm hiểu Box Model và border để hoàn thiện phần trình bày khối.
