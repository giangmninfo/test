Căn lề văn bản: left/right/center/justify, giá trị logic start/end, trong ô bảng và lưu ý căn khối kèm ví dụ chạy thật (tách HTML/CSS).

Mô hình hộp: content, padding, border, margin; cách tính kích thước tổng và box-sizing (content-box/border-box) kèm ví dụ chạy thật (tách HTML/CSS).

CSS Display

Thuộc tính display: block, inline, inline-block, none, flex, grid — kèm sơ đồ so sánh trực quan và ví dụ chạy thật (tách HTML/CSS).

Modern Layout Systems

CSS Flexbox

Bố cục linh hoạt một chiều: display:flex, flex-direction, justify-content, align-items, flex-wrap, gap và thuộc tính trên item — kèm sơ đồ trục & ví dụ chạy thật (tách HTML/CSS).

CSS justify-content

Căn theo trục chính: flex-start/center/flex-end, space-between/around/evenly và trong grid — kèm sơ đồ 6 giá trị & ví dụ chạy thật (tách HTML/CSS).

CSS align-items

Căn theo trục phụ: stretch, center, flex-start/end, baseline và align-self — kèm sơ đồ minh hoạ & ví dụ chạy thật (tách HTML/CSS).

CSS align-content

Căn các dòng (nhiều hàng) theo trục phụ khi flex-wrap: center, space-between/around, stretch và trong grid — kèm ví dụ chạy thật (tách HTML/CSS).

CSS Grid Layout

Bố cục lưới 2 chiều: display:grid, cột/hàng, đơn vị fr, repeat(), gap, đặt item (span) và căn chỉnh — kèm sơ đồ lưới & ví dụ chạy thật (tách HTML/CSS).

CSS grid-template-columns

Định nghĩa cột lưới: cố định, fr, repeat(), minmax(), auto-fit cho lưới responsive — kèm ví dụ chạy thật (tách HTML/CSS).

CSS grid gap

Khoảng cách lưới: gap, row-gap, column-gap (và grid-gap cũ); dùng được cho cả Flexbox — kèm ví dụ chạy thật (tách HTML/CSS).

CSS Transform

Biến đổi: translate, rotate, scale, skew, kết hợp nhiều hàm và transform-origin — kèm ví dụ chạy thật (tách HTML/CSS).

CSS Animations

Forms Layout

Navbar Text

Progress
