Nhóm HTML

HTML Basic

HTML Introduction

Giới thiệu HTML: HTML là gì, cấu trúc tài liệu, cách hoạt động, ưu/nhược điểm kèm editor chạy trực tiếp.

HTML Editors

Trình soạn thảo HTML: các loại editor, công cụ phổ biến, tạo tệp .html từng bước và bảng so sánh.

HTML Basics

Kiến thức nền tảng về HTML kèm trình soạn mã trực tiếp (Try it yourself).

Structure & Elements

HTML Attributes

Thuộc tính HTML: cú pháp, src/alt, id/class, href, style, lang, boolean và thuộc tính toàn cục kèm ví dụ.

HTML Headings

Thẻ tiêu đề h1–h6: cấp bậc, vai trò, SEO, tùy chỉnh CSS và thực hành tốt kèm ví dụ chạy trực tiếp.

HTML Paragraphs

Thẻ đoạn văn <p>: khoảng trắng, <pre>, <br>, <hr>, căn lề và lỗi thường gặp kèm ví dụ chạy trực tiếp.

HTML Text Formatting

Định dạng văn bản: đậm/nghiêng, mark, small, del/ins, sub/sup và thẻ ngữ nghĩa vs trình bày kèm ví dụ chạy trực tiếp.

Block & Inline Elements

Phần tử khối vs nội tuyến: hành vi, danh sách, <div>/<span>, quy tắc lồng nhau kèm hình minh hoạ và ví dụ chạy trực tiếp.

HTML Charsets

Bảng mã ký tự: ASCII, ANSI, ISO-8859-1, UTF-8, cách khai báo charset và bảng ASCII kèm ví dụ chạy trực tiếp.

Meta Tags cho SEO

Thẻ meta HTML cho SEO kèm công cụ xem trước kết quả tìm kiếm.

List

HTML Lists

Tổng quan danh sách: <ul>, <ol>, <dl> và danh sách lồng nhau kèm ví dụ chạy trực tiếp.

Ordered Lists

Danh sách có thứ tự <ol>: type (1/A/a/I/i), start, reversed, value và lồng nhau kèm ví dụ chạy trực tiếp.

Unordered Lists

Danh sách không thứ tự <ul>: list-style-type, none, lồng nhau, menu điều hướng kèm ví dụ chạy trực tiếp.

Description Lists

Danh sách mô tả <dl>/<dt>/<dd>: nhiều mô tả, lồng nhau, FAQ/glossary kèm ví dụ chạy trực tiếp.

Visuals & Media

HTML Colors

Màu sắc: tên màu, RGB/RGBA, HEX, HSL/HSLA, cách tô màu chữ/nền/viền kèm bảng màu và ví dụ chạy trực tiếp.

HTML Links

Liên kết <a>: href, target, URL tuyệt đối/tương đối, mailto/tel, bookmark, ảnh/nút làm link kèm ví dụ chạy trực tiếp.

HTML Images

Hình ảnh <img>: src/alt, kích thước, viền, ảnh làm link, đường dẫn và định dạng ảnh kèm ví dụ chạy trực tiếp.

HTML5 Video

Nhúng video <video>: controls, source đa định dạng, autoplay/muted, loop, poster, track phụ đề kèm ví dụ chạy trực tiếp.

HTML Favicon

Biểu tượng trang web: thẻ <link rel="icon">, định dạng ICO/PNG/SVG, nhiều kích thước và favicon emoji kèm ví dụ chạy trực tiếp.

Layouts & Designs

HTML Tables

Bảng <table>: tr/th/td, thead/tbody/tfoot, caption, colspan/rowspan và tô màu viền bằng CSS kèm ví dụ chạy trực tiếp.

HTML Iframes

Nhúng trang <iframe>: src, kích thước, bỏ viền, name/target, nhúng YouTube và bảo mật sandbox/lazy kèm ví dụ chạy trực tiếp.

HTML Layout

Bố cục trang: header/nav/main/aside/footer, thẻ ngữ nghĩa và các kỹ thuật Flexbox, Grid, float, responsive kèm ví dụ chạy trực tiếp.

HTML File Paths

Đường dẫn tệp: tuyệt đối vs tương đối, cùng thư mục, thư mục con, ../ lên cấp và / từ gốc website kèm ví dụ chạy trực tiếp.

Projects & Advanced Topics

Semantic Elements

Các phần tử ngữ nghĩa HTML5 kèm editor minh họa bố cục trực tiếp.

HTML Forms

Biểu mẫu HTML, các loại input và một form demo hoạt động thật.

HTML URL Encoding

Mã hóa URL (percent-encoding): vì sao cần, bảng ký tự %XX, khoảng trắng, Unicode UTF-8 và công cụ mã hóa trực tiếp.

Responsive Web Design

Thiết kế web đáp ứng: meta viewport, media queries, lưới linh hoạt, ảnh đáp ứng, đơn vị %/rem/vw kèm ví dụ chạy trực tiếp.

Nhóm HTML5

HTML5 Basic

HTML5 Introduction

Giới thiệu HTML5: HTML5 là gì, doctype gọn, tính năng nổi bật, phần tử mới, so sánh HTML vs HTML5 kèm ví dụ chạy trực tiếp.

Nhóm CSS

CSS Basic

CSS Introduction

Giới thiệu CSS: cú pháp, 3 cách chèn CSS, bộ chọn kèm editor chạy trực tiếp.

CSS Syntax

Cú pháp CSS: selector, declaration, property/value và các loại bộ chọn.

CSS Combinators

4 combinator: hậu duệ, con, anh em liền kề và anh em chung, kèm ví dụ chạy thật.

CSS Selectors

Bộ chọn cơ bản, thuộc tính, pseudo-class và pseudo-element kèm ví dụ chạy thật.

Styling & Properties

CSS Colors

Tên màu, HEX, RGB/RGBA, HSL/HSLA kèm công cụ chọn màu và ví dụ chạy thật.

CSS Background

Màu nền, hình nền, repeat, position, size, shorthand và gradient kèm ví dụ chạy thật.

CSS Borders

Kiểu, độ dày, màu viền, viền từng cạnh, shorthand và border-radius kèm ví dụ chạy thật.

CSS Margins & Padding

Khoảng cách trong/ngoài, cú pháp rút gọn, từng cạnh và căn giữa kèm ví dụ chạy thật.

CSS Padding

Khoảng đệm trong, từng cạnh, rút gọn, box-sizing và padding theo % kèm ví dụ chạy thật.

CSS Overflow

Xử lý nội dung tràn: visible, hidden, scroll, auto và overflow-x/y kèm ví dụ chạy thật.

CSS Height & Width

Đặt kích thước, đơn vị, %, min/max-width và min/max-height kèm ví dụ chạy thật.

Text & Fonts

CSS Text Formatting

Định dạng văn bản: color, text-align, text-decoration, text-transform, indent, spacing, line-height và text-shadow kèm ví dụ chạy thật.
