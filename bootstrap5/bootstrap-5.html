Bootstrap 5 — Giới thiệu Bootstrap 5

Cấp độ: Cơ bản Cập nhật: 18/06/2026 389K lượt đọc

Bootstrap là framework CSS mã nguồn mở, miễn phí và phổ biến nhất để xây dựng giao diện web responsive, ưu tiên di động (mobile-first) nhanh chóng. Bootstrap 5 là phiên bản lớn mới nhất, nổi bật ở chỗ loại bỏ phụ thuộc jQuery, dùng JavaScript thuần, bổ sung nhiều tiện ích và hệ thống lưới linh hoạt hơn.

Điểm mới quan trọng nhất: Bootstrap 5 không còn cần jQuery; bỏ hỗ trợ Internet Explorer; thêm breakpoint xxl, biến CSS (CSS variables) và kho icon riêng (Bootstrap Icons).

Vì sao dùng Bootstrap?

  • Dựng giao diện đẹp, responsive rất nhanh nhờ lớp tiện ích có sẵn.
  • Hệ thống lưới 12 cột mạnh mẽ, dễ chia bố cục.
  • Nhiều component dựng sẵn: nút, thẻ, navbar, modal, form…
  • Tương thích đa trình duyệt, nhất quán trên mọi thiết bị.
  • Cộng đồng lớn, tài liệu phong phú.

Tính năng nổi bật của Bootstrap 5

Tính năngMô tả
Không cần jQueryDùng JavaScript thuần (vanilla JS), nhẹ và nhanh hơn.
Mobile-firstThiết kế ưu tiên di động, mở rộng dần lên màn hình lớn.
Grid 12 cộtThêm breakpoint xxl (≥1400px), lớp g-* cho gutter.
CSS variablesTùy biến giao diện dễ dàng qua biến CSS.
Utilities APIHệ thống lớp tiện ích (spacing, màu, flex…) phong phú.
Bootstrap IconsBộ icon SVG miễn phí đi kèm.

Cách cài đặt Bootstrap 5

Cách nhanh nhất là nhúng qua CDN. Thêm CSS vào <head> và JS trước thẻ </body>:

<!-- CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- JS (bundle gồm Popper) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Ngoài ra có thể tải về (download) hoặc cài bằng npm: npm install bootstrap.

Ưu & nhược điểm

  • Ưu: phát triển nhanh, responsive sẵn, nhiều component, tài liệu tốt, nhẹ hơn (bỏ jQuery).
  • Nhược: nhiều site trông giống nhau nếu không tùy biến; kích thước file có thể lớn nếu dùng ít; cần học hệ thống lớp.

Tóm tắt

Bootstrap 5 là framework CSS mạnh mẽ giúp dựng giao diện web responsive nhanh chóng. Điểm nổi bật là không còn phụ thuộc jQuery, ưu tiên di động, hệ thống lưới 12 cột với breakpoint xxl, dùng CSS variables và kèm Bootstrap Icons. Cách nhanh nhất để bắt đầu là nhúng qua CDN, sau đó dùng các container, grid và component dựng sẵn.
