Bootstrap 5 Utilities — Lớp tiện ích

Cấp độ: Cơ bản Cập nhật: 18/06/2026 262K lượt đọc

Utilities (lớp tiện ích) là các lớp CSS nhỏ, đơn mục đích của Bootstrap giúp tạo kiểu nhanh ngay trên HTML mà không cần viết CSS riêng — ví dụ canh giữa, đặt màu, thêm khoảng cách, đổ bóng, ẩn/hiện… Đây là cách dựng giao diện cực nhanh theo phong cách "utility-first".

Quy ước đặt tên: hầu hết theo dạng {thuộc-tính}{cạnh}-{breakpoint}-{giá-trị}, ví dụ mt-3 (margin-top mức 3), px-md-4 (padding ngang mức 4 từ md).

Thực hành tốt

  • Ưu tiên utilities cho tinh chỉnh nhỏ thay vì viết CSS riêng.
  • Kết hợp breakpoint (d-md-flex) để responsive.
  • Không lạm dụng quá nhiều lớp khiến HTML rối — gom lại thành class CSS khi cần.
  • Tận dụng mx-auto, text-center để canh nhanh.

Tóm tắt

Utilities là kho lớp tiện ích đơn mục đích của Bootstrap 5 cho spacing, màu, văn bản, display, flex, sizing, viền, bóng, vị trí… Chúng giúp tạo kiểu nhanh ngay trên HTML, hỗ trợ responsive qua infix breakpoint, và là nền tảng cho phong cách utility-first.

Bước tiếp theo: Xem Z-index để quản lý thứ tự xếp chồng, hoặc quay lại Grid System để dựng bố cục.
