Bootstrap 5 Dropdowns — Menu thả xuống

Cấp độ: Cơ bản Cập nhật: 21/06/2026 301K lượt đọc

Dropdowns (menu thả xuống) hiển thị danh sách lựa chọn khi bấm vào nút. Bootstrap 5 dựng dropdown bằng tiện ích JavaScript (Popper) nên cần Bootstrap JS bundle (đã nhúng trong ví dụ).

Cấu trúc: .dropdown bọc nút .dropdown-toggle (có data-bs-toggle="dropdown") và <ul class="dropdown-menu"> chứa các .dropdown-item.

Thực hành tốt

  • Nhớ nhúng Bootstrap JS bundle (gồm Popper) để dropdown hoạt động.
  • Nút mở dùng .dropdown-toggle + data-bs-toggle="dropdown".
  • Dùng .dropdown-header/.dropdown-divider để nhóm mục cho rõ ràng.
  • Đặt aria-expanded phù hợp cho trợ năng (Bootstrap tự cập nhật).

Tóm tắt

Dropdowns gồm .dropdown > .dropdown-toggle (data-bs-toggle="dropdown") + .dropdown-menu > .dropdown-item. Tùy biến bằng header/divider/active, đổi hướng (.dropup/.dropend/.dropstart), nút chia và menu nền tối. Cần Bootstrap JS.

Bước tiếp theo: Xem List Group để hiển thị danh sách nội dung.
