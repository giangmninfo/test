Bootstrap 5 Layout Breakpoints — Điểm ngắt bố cục

Cấp độ: Cơ bản Cập nhật: 18/06/2026 241K lượt đọc

Breakpoint (điểm ngắt) là các ngưỡng chiều rộng màn hình mà tại đó bố cục của trang web thay đổi. Bootstrap 5 dùng breakpoint để xây dựng giao diện responsive, mobile-first: cùng một bộ mã sẽ tự sắp xếp lại cho phù hợp với điện thoại, máy tính bảng và máy tính để bàn.

Cốt lõi: Bootstrap có 6 breakpoint mặc định, mỗi cái gắn với một infix lớp (sm, md, lg, xl, xxl) — dùng cho grid, hiển thị, khoảng cách…

6 breakpoint mặc định

  • Extra small (xs): < 576px — mặc định, không có infix.
  • Small (sm): ≥ 576px.
  • Medium (md): ≥ 768px.
  • Large (lg): ≥ 992px.
  • Extra large (xl): ≥ 1200px.
  • Extra extra large (xxl): ≥ 1400px.

Tư duy mobile-first

Bootstrap thiết kế theo mobile-first: kiểu mặc định áp dụng cho màn hình nhỏ (xs), rồi các breakpoint lớn hơn ghi đè khi màn hình rộng ra. Vì vậy col-md-6 nghĩa là "từ md trở lên thì chiếm 6/12 cột", còn nhỏ hơn md thì mặc định chiếm cả hàng.

Media query bên dưới

Mỗi breakpoint tương ứng với một @media (min-width: ...):

/* sm */  @media (min-width: 576px)  { ... }
/* md */  @media (min-width: 768px)  { ... }
/* lg */  @media (min-width: 992px)  { ... }
/* xl */  @media (min-width: 1200px) { ... }
/* xxl */ @media (min-width: 1400px) { ... }

Dùng breakpoint trong grid

Đặt infix vào lớp cột để đổi cách chia theo màn hình. Ví dụ dưới: mỗi cột chiếm cả hàng trên màn hình rất nhỏ, 1/2 từ sm, và 1/4 từ md. Hãy thu hẹp khung kết quả để thấy bố cục đổi:

Min-width & max-width

Mặc định các lớp dùng kiểu min-width (áp dụng từ breakpoint trở lên). Bootstrap còn có biến thể giới hạn trên cho một số tiện ích, nhưng quy ước phổ biến nhất vẫn là min-width (mobile-first).

Ẩn/hiện theo breakpoint

Kết hợp lớp d-* với breakpoint để ẩn/hiện phần tử. Ví dụ d-none d-md-block: ẩn ở màn nhỏ, hiện từ md trở lên:

Thực hành tốt

  • Thiết kế mobile-first: đặt kiểu cho màn nhỏ trước, mở rộng dần bằng infix lớn hơn.
  • Chỉ thêm infix khi thực sự cần đổi bố cục ở breakpoint đó.
  • Dùng xxl cho màn hình rất rộng nếu cần tận dụng không gian.
  • Kiểm thử ở nhiều kích thước (DevTools → chế độ thiết bị).
  • Có thể tùy biến giá trị breakpoint qua biến Sass nếu dùng bản nguồn.

Thử viết code ngay (Try it yourself)

Chỉnh sửa mã (đã nhúng Bootstrap 5), kết quả hiển thị ngay bên phải. Thu hẹp khung kết quả để thấy breakpoint hoạt động. Bấm Chạy hoặc Đặt lại.

Tóm tắt

Breakpoint là các ngưỡng chiều rộng giúp Bootstrap 5 tạo giao diện responsive theo hướng mobile-first. Có 6 breakpoint: xs (<576), sm (≥576), md (≥768), lg (≥992), xl (≥1200), xxl (≥1400). Mỗi cái ứng với một @media (min-width) và một infix lớp dùng cho grid, hiển thị, khoảng cách… Đặt infix phù hợp để bố cục tự thích ứng theo thiết bị.
