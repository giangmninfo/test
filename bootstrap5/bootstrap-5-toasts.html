Bootstrap 5 Toasts — Thông báo nổi

Cấp độ: Cơ bản Cập nhật: 21/06/2026 243K lượt đọc

Toasts là thông báo nhỏ, nhẹ, tạm thời (giống thông báo đẩy) hiện lên rồi tự ẩn — dùng để báo thành công, lỗi, cập nhật… Toasts dựa trên JavaScript của Bootstrap nên cần Bootstrap JS bundle (đã nhúng trong ví dụ).

Cấu trúc: .toast > .toast-header + .toast-body. Toast ẩn mặc định; thêm .show để hiện sẵn, hoặc gọi JS .show() để bật.

Cấu trúc

  • .toast: khung ngoài (kèm role="alert").
  • .toast-header: tiêu đề + nút đóng (.btn-close với data-bs-dismiss="toast").
  • .toast-body: nội dung thông báo.

Thực hành tốt

  • Nhớ nhúng Bootstrap JS bundle để toast hoạt động.
  • Thêm role="alert" + aria-live="assertive" cho trợ năng.
  • Dùng .toast-container + position-fixed để xếp chồng toast.
  • Đặt thời gian tự ẩn hợp lý; cho nút đóng thủ công.

Tóm tắt

Toasts là thông báo nhỏ tạm thời: .toast > .toast-header + .toast-body. Hiện sẵn bằng .show hoặc bật bằng JS (new bootstrap.Toast(el).show()); đặt vị trí bằng .toast-container + position-*. Cần Bootstrap JS.
