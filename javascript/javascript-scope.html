JavaScript Scope — Phạm vi của biến

Cấp độ: Nâng cao Cập nhật: 06/07/2026 556K lượt đọc

Scope (phạm vi) quyết định nơi một biến có thể được nhìn thấy và sử dụng trong code. Hiểu scope giúp tránh xung đột tên, "rò rỉ" biến ra toàn cục và các bug khó thấy.

Ba mức chính: global (toàn cục), function (trong hàm) và block (trong cặp { }). let/const có block scope, còn var chỉ có function scope. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Tóm tắt

Scope quyết định nơi truy cập được một biến. Có global (toàn cục), function (trong hàm), block (trong { }) và lexical (hàm thấy biến nơi được định nghĩa). let/const có block scope; var chỉ có function scope. Khi tìm biến, JS đi theo scope chain từ trong ra ngoài; biến trong có thể che (shadow) biến ngoài cùng tên. Nên dùng scope hẹp & hạn chế biến toàn cục.
