Giới thiệu Lập trình hướng đối tượng (OOP) trong JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 374K lượt đọc

Lập trình hướng đối tượng (OOP — Object-Oriented Programming) là cách tổ chức code quanh các đối tượng — gói chung dữ liệu (thuộc tính) và hành vi (method). Mục tiêu: code dễ tái sử dụng, dễ mở rộng và dễ bảo trì hơn.

Trong JavaScript: OOP thường dùng cú pháp class (ra mắt từ ES6) — bên dưới vẫn là prototype. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Đặt tên class viết hoa chữ cái đầu (NguoiDung, HinhTron).
  • Đóng gói dữ liệu nhạy cảm bằng trường #; cho truy cập qua method (getter/setter).
  • Dùng kế thừa khi có quan hệ "là một" (Chó là một Động vật); ưu tiên thành phần (composition) khi phù hợp.
  • Mỗi class nên có một trách nhiệm rõ ràng.

Tóm tắt

OOP tổ chức code quanh đối tượng (gói dữ liệu + hành vi), dựa trên 4 trụ cột: đóng gói (encapsulation, trường #), trừu tượng (abstraction), kế thừa (inheritance, extends/super) và đa hình (polymorphism, ghi đè method). Trong JavaScript, OOP dùng cú pháp class với constructor, method, static.

Bước tiếp theo: Tiếp theo trong nhóm OOP: JavaScript Classes, Inheritance, Encapsulation, Prototype… (sắp ra mắt). Ôn lại Object Constructors.
