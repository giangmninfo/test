JavaScript Errors — Throw và Try...Catch

Cấp độ: Trung cấp Cập nhật: 30/06/2026 389K lượt đọc

Khi thực thi code, JavaScript có thể gặp lỗi — do cú pháp sai, dữ liệu không hợp lệ, hoặc lập trình viên chủ động báo lỗi. Bộ ba try, catch, finally cùng câu lệnh throw cho phép kiểm soát lỗi thay vì để chương trình dừng đột ngột.

Vai trò từng từ khoá: try định nghĩa đoạn code cần thử; throw tạo lỗi tuỳ chỉnh; catch xử lý lỗi; finally chạy code sau cùng (dù thành công hay lỗi). Ví dụ dưới chỉ dùng JavaScript, in ra console.

Bảng giá trị name của Error

Sáu giá trị name tiêu chuẩn của đối tượng Error:

Giá trị nameÝ nghĩa
RangeErrorSố nằm ngoài phạm vi cho phép.
ReferenceErrorDùng một biến chưa được khai báo.
SyntaxErrorSai cú pháp khi phân tích code.
TypeErrorDùng giá trị sai kiểu dữ liệu.
EvalErrorLỗi liên quan tới hàm eval() (ít gặp).
URIErrorDùng sai hàm mã hoá URI (decodeURIComponent…).

Thực hành tốt

  • Luôn throw new Error("...") thay vì ném chuỗi thuần để giữ chuẩn.
  • Chỉ bọc try quanh đoạn thật sự có thể lỗi.
  • Dùng finally để dọn dẹp (đóng file/kết nối, ẩn loading).
  • Không để catch rỗng — luôn ghi log hoặc phản hồi lỗi.

Tóm tắt

try bọc đoạn code có thể lỗi; throw chủ động ném lỗi; catch bắt & xử lý; finally luôn chạy sau cùng. Khi lỗi xảy ra, JavaScript tạo đối tượng Error với name & message — có 6 giá trị name chuẩn (RangeError, ReferenceError, SyntaxError, TypeError, EvalError, URIError). Nên ném Error và luôn xử lý lỗi thay vì bỏ qua.
