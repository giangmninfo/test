DOM (Document Object Model) — Mô hình đối tượng tài liệu

Cấp độ: Trung cấp Cập nhật: 30/06/2026 603K lượt đọc

DOM (Document Object Model) là cách trình duyệt biểu diễn một trang HTML dưới dạng cây các đối tượng. Nhờ DOM, JavaScript có thể đọc và thay đổi nội dung, cấu trúc, kiểu dáng của trang sau khi trang đã tải — giúp trang web trở nên "sống động", tương tác.

Ghi nhớ: mỗi thẻ HTML trở thành một node (nút) trong cây DOM; JavaScript truy cập cây này qua đối tượng toàn cục document. Các ví dụ dưới dùng HTML + CSS + JS và hiển thị kết quả trực tiếp.

Cây DOM (DOM tree)

Một tài liệu HTML được tổ chức thành cây phân cấp: document → html → head/body → các phần tử con… Mỗi nút có thể có nút cha, nút con và nút anh em.

Xét vai trò từng thẻ trong cùng đoạn HTML: thẻ gốc, thẻ chứa (container) và thẻ con (child):

Thuật ngữÝ nghĩa
DocumentToàn bộ tài liệu — gốc của cây DOM.
Element nodeMột thẻ HTML (vd <p>, <div>).
Text nodeĐoạn văn bản bên trong phần tử.
AttributeThuộc tính của phần tử (vd id, class).

Đối tượng document

document là "cửa ngõ" vào DOM — mọi thao tác tìm, sửa, tạo phần tử đều bắt đầu từ đây. Về mặt kỹ thuật, Document kế thừa từ Node, và Node kế thừa từ EventTarget — nhờ đó document vừa là một nút trong cây DOM, vừa nhận/bắt được sự kiện:

Tóm tắt

DOM là cây đối tượng biểu diễn trang HTML, truy cập qua document. JavaScript dùng DOM để tìm phần tử (getElementById, querySelector), đổi nội dung (textContent, innerHTML), đổi style/class (style, classList), đổi thuộc tính (setAttribute), tạo/xoá phần tử (createElement, remove) và bắt sự kiện (addEventListener) — giúp trang web tương tác, sống động.
