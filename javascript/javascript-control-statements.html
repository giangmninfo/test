Control Statements in JavaScript — Câu lệnh điều khiển luồng

Cấp độ: Cơ bản Cập nhật: 23/06/2026 412K lượt đọc

Câu lệnh điều khiển (control statements) quyết định luồng thực thi của chương trình — chạy đoạn nào, bỏ qua đoạn nào, hay lặp lại bao nhiêu lần. Gồm ba nhóm: rẽ nhánh (if, switch), vòng lặp (for, while) và câu lệnh nhảy (break, continue).

Mặc định: mã JavaScript chạy tuần tự từ trên xuống. Câu lệnh điều khiển cho phép thay đổi trật tự đó. Các ví dụ dưới chỉ dùng JavaScript, in kết quả ra console.

Thực hành tốt

  • Luôn dùng { } bao thân lệnh, kể cả khi chỉ một dòng — tránh lỗi khó thấy.
  • Đừng quên break trong switch (trừ khi cố ý cho "rơi xuống").
  • Đảm bảo vòng while có điều kiện dừng để không lặp vô hạn.
  • Dùng for...of cho mảng, for...in cho object.
