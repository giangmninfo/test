How to Select DOM Elements — Chọn phần tử trong DOM

Cấp độ: Trung cấp Cập nhật: 30/06/2026 421K lượt đọc

Trước khi thay đổi một phần tử trên trang, JavaScript phải chọn (select) được nó từ DOM. Có nhiều cách chọn — theo id, class, tên thẻ hoặc CSS selector. Mọi thao tác đều bắt đầu từ đối tượng document.

Nên nhớ: hai phương thức hiện đại & linh hoạt nhất là querySelector (chọn một) và querySelectorAll (chọn nhiều) vì dùng cú pháp CSS quen thuộc. Các ví dụ dưới dùng HTML + CSS + JS và hiển thị kết quả trực tiếp.

Thực hành tốt

  • Ưu tiên querySelector/querySelectorAll — cú pháp CSS gọn, linh hoạt.
  • getElementById vẫn nhanh & rõ ràng khi chọn theo id.
  • Nhớ getElementsBy... trả về tập, cần vòng lặp; kết quả rỗng vẫn là tập (không phải null).
  • Kiểm tra null sau querySelector/getElementById trước khi dùng.

Tóm tắt

JavaScript chọn phần tử DOM qua document: getElementById (theo id), getElementsByClassName/getElementsByTagName (trả về HTMLCollection "sống"), querySelector (phần tử đầu tiên khớp CSS selector) và querySelectorAll (NodeList "tĩnh"). Có thể gọi trên một phần tử để giới hạn phạm vi tìm. Nên ưu tiên querySelector(All); luôn kiểm tra null trước khi dùng.
