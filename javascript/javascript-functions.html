Functions in JavaScript — Hàm trong JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 612K lượt đọc

Hàm (function) là một khối lệnh có tên, được viết một lần và dùng lại nhiều lần. Hàm nhận dữ liệu vào qua tham số, xử lý rồi trả về (return) kết quả — giúp code gọn, dễ bảo trì và tránh lặp lại.

Ghi nhớ: định nghĩa hàm bằng function, function expression hoặc arrow function; gọi hàm bằng tênHàm(đốiSố). Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Các cách định nghĩa hàm

Khai báo & gọi hàm

Dùng từ khoá function; gọi hàm bằng tên kèm dấu ngoặc:

Tham số & return

Hàm nhận tham số và trả về giá trị bằng return (gặp return là dừng):

Function expression

Gán hàm vào một biến — hàm trở thành "giá trị" có thể truyền đi:

Arrow function (=>)

Cú pháp ngắn gọn; một dòng có thể bỏ {} và return:

Tham số mặc định

Gán giá trị mặc định khi đối số không được truyền:

Rest parameters (...)

Gom nhiều đối số thành một mảng — hàm nhận số đối số tuỳ ý:

Callback function

Hàm được truyền vào hàm khác để gọi lại sau (nền tảng của lập trình bất đồng bộ):

Phạm vi (scope) & hoisting

Biến trong hàm là cục bộ; khai báo function được "kéo lên" (hoisting):

IIFE — hàm tự gọi ngay

Hàm định nghĩa và chạy ngay lập tức, tạo phạm vi riêng:

Thực hành tốt

  • Đặt tên hàm rõ nghĩa, theo dạng động từ (tinhTong, layTen).
  • Mỗi hàm nên làm một việc; giữ hàm ngắn gọn.
  • Dùng arrow function cho callback ngắn; dùng function khi cần this động.
  • Luôn return giá trị thay vì sửa biến toàn cục.

Tóm tắt

Hàm đóng gói khối lệnh để dùng lại: nhận tham số, trả về bằng return. Có ba cách định nghĩa chính: declaration (function f(){}), expression (const f = function(){}) và arrow (const f = () => {}). Hỗ trợ tham số mặc định, rest (...args), callback, IIFE; biến trong hàm có phạm vi cục bộ.
