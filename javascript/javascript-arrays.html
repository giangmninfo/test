JavaScript Arrays — Mảng trong JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 521K lượt đọc

Mảng (array) là một biến lưu nhiều giá trị theo thứ tự, truy cập qua chỉ số (index) bắt đầu từ 0. Mảng có thể chứa số, chuỗi, boolean, object — thậm chí cả mảng khác.

Ghi nhớ: chỉ số đầu tiên là 0, phần tử cuối có chỉ số length - 1. Các ví dụ dưới chỉ dùng JavaScript, in kết quả ra console.

Tóm tắt

Mảng lưu nhiều giá trị theo thứ tự, truy cập qua chỉ số từ 0. Thêm/xoá bằng push/pop/shift/unshift; duyệt bằng for...of/forEach; tìm kiếm với indexOf/includes; cắt với slice/splice; biến đổi bằng map/filter/reduce; sắp xếp & ghép với sort/join/concat. Kiểm tra bằng Array.isArray().
