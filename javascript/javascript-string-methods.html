JavaScript String Methods — Các phương thức chuỗi

Cấp độ: Cơ bản Cập nhật: 23/06/2026 467K lượt đọc

Phương thức chuỗi (string methods) là các hàm dựng sẵn để thao tác văn bản: tìm kiếm, cắt, thay thế, đổi hoa/thường, căn lề… Vì chuỗi bất biến, mọi phương thức đều trả về chuỗi/giá trị mới, không sửa chuỗi gốc.

Ghi nhớ: luôn gán lại kết quả (vd s = s.trim()). Chỉ số ký tự bắt đầu từ 0. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Luôn gán lại kết quả vì chuỗi bất biến: s = s.toUpperCase().
  • Dùng includes() để kiểm tra "có chứa" thay vì indexOf() !== -1.

Tóm tắt

Phương thức chuỗi giúp: truy cập/tìm kiếm (charAt/charCodeAt/indexOf/includes/search), cắt (slice/substring/split), biến đổi (toUpperCase/toLowerCase/trim/replace/replaceAll), căn lề (padStart/padEnd/repeat), regex (match) và so sánh (localeCompare). Tất cả trả về giá trị mới.
