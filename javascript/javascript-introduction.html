Introduction to JavaScript — Giới thiệu JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 512K lượt đọc

JavaScript (JS) là ngôn ngữ lập trình kịch bản phổ biến nhất cho web. Cùng với HTML (nội dung) và CSS (giao diện), JavaScript mang lại tính tương tác & logic: xử lý sự kiện, thay đổi nội dung động, gọi API… JS còn chạy ở máy chủ (Node.js).

Bộ ba của web: HTML = cấu trúc, CSS = trình bày, JavaScript = hành vi/tương tác. Các ví dụ dưới đây gồm cả HTML + CSS + JS nên bạn thấy kết quả hiển thị trực tiếp.

Đặc điểm chính

Những khả năng nổi bật giúp JavaScript "làm trang web sống động":

  • Thông dịch, chạy trực tiếp trong trình duyệt.
  • Kiểu động: không cần khai báo kiểu cho biến.
  • Đa phong cách: thủ tục, hướng đối tượng, hàm.
  • Chạy cả phía client (trình duyệt) lẫn server (Node.js).

Nhúng JavaScript vào HTML

Đặt mã trong thẻ <script> hoặc liên kết file .js ngoài:

<script>
  console.log("Xin chào!");
</script>

<script src="app.js"></script>

JavaScript dùng để làm gì?

  • Tương tác trang: nút bấm, form, hiệu ứng, cập nhật DOM động.
  • Gọi API, tải dữ liệu không tải lại trang (fetch/AJAX).
  • Ứng dụng web/mobile (React, Vue…), máy chủ (Node.js), game…

Thực hành tốt

  • Dùng let/const thay cho var.
  • Đặt tên biến rõ nghĩa; nhất quán dấu ;.
  • Tách JS ra file .js khi dự án lớn dần.
  • Dùng console.log để kiểm tra giá trị khi học & gỡ lỗi.

Tóm tắt

JavaScript tạo tương tác cho web (cùng HTML & CSS). Nhúng qua <script>; thay đổi nội dung trang qua DOM; in giá trị bằng console.log; khai báo biến bằng let/const; có kiểu dữ liệu, hàm và xử lý sự kiện. Chạy ở cả trình duyệt lẫn Node.js.

Bước tiếp theo: Tiếp theo trong JavaScript Basics: Variables, Data Types, Operators… (sắp ra mắt). Ôn lại HTML và CSS để kết hợp cùng JavaScript.
