Objects in JavaScript — Đối tượng trong JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 587K lượt đọc

Object (đối tượng) là kiểu dữ liệu lưu dữ liệu dưới dạng các cặp khoá : giá trị (key : value). Khác mảng (dùng chỉ số), object truy cập dữ liệu qua tên thuộc tính — rất hợp để mô tả một "thực thể" như người dùng, sản phẩm…

Ghi nhớ: giá trị (value) có thể là số, chuỗi, mảng, object khác — hoặc hàm (khi đó gọi là method). Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Tóm tắt

Object lưu dữ liệu dạng cặp key : value, truy cập bằng obj.key hoặc obj["key"]. Có thể thêm/sửa/xoá thuộc tính, định nghĩa method (dùng this), lồng object/mảng. Duyệt bằng for...in hoặc Object.keys/values/entries; kiểm tra bằng in/hasOwnProperty; sao chép & gộp bằng Object.assign/spread; khoá bằng Object.freeze.

Bước tiếp theo: Tiếp theo trong nhóm Function & Object: Object Methods, this keyword, Classes… (sắp ra mắt). Ôn lại Function Overloading.
