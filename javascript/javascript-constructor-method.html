JavaScript Constructor Method — Phương thức constructor

Cấp độ: Trung cấp Cập nhật: 30/06/2026 318K lượt đọc

Constructor method là một phương thức đặc biệt tên constructor() bên trong class, tự động chạy khi tạo object bằng new. Nhiệm vụ chính: khởi tạo các thuộc tính ban đầu cho object thông qua this.

Ghi nhớ: mỗi class chỉ có một constructor(). Nếu không viết, JavaScript tự thêm một constructor rỗng. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Tóm tắt

Constructor method (constructor()) là phương thức đặc biệt tự chạy khi tạo object bằng new, dùng để khởi tạo thuộc tính qua this. Mỗi class chỉ có một constructor; nếu bỏ trống JavaScript tự thêm bản rỗng (hoặc gọi super(...args) ở lớp con). Có thể kiểm tra dữ liệu trong constructor; lớp con phải gọi super() trước khi dùng this.
