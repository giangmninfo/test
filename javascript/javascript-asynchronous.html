Asynchronous JavaScript — Lập trình bất đồng bộ

Cấp độ: Trung cấp Cập nhật: 30/06/2026 445K lượt đọc

Lập trình bất đồng bộ (asynchronous) cho phép chương trình không phải chờ một tác vụ tốn thời gian (gọi mạng, đọc file, hẹn giờ…) hoàn tất mới chạy tiếp. JavaScript vốn đơn luồng, nhờ cơ chế bất đồng bộ mà trang web vẫn mượt, không bị "đóng băng".

Đồng bộ (sync): chạy tuần tự, việc sau phải chờ việc trước. Bất đồng bộ (async): khởi động tác vụ rồi chạy tiếp, kết quả xử lý sau. Các ví dụ dưới chỉ dùng JavaScript, in ra console (các dòng async xuất hiện sau).

Vì sao cần bất đồng bộ?

Nếu một tác vụ chậm chạy đồng bộ, cả trang sẽ đứng im cho tới khi nó xong. Async giúp tránh điều đó.

Thực hành tốt

  • Ưu tiên async/await cho code dễ đọc; dùng try/catch để bắt lỗi.
  • Tránh lồng callback nhiều tầng (callback hell) — chuyển sang Promise/async.
  • Luôn xử lý lỗi với .catch() hoặc try/catch.
  • Nhớ: code đồng bộ luôn chạy trước tác vụ bất đồng bộ.

Tóm tắt

Async giúp JavaScript (đơn luồng) khởi động tác vụ tốn thời gian rồi chạy tiếp mà không bị chặn. Ba cách chính: callback (dễ callback hell), Promise (.then()/.catch()) và async/await (dễ đọc nhất, dùng try/catch). Cơ chế event loop đảm bảo code đồng bộ chạy trước, tác vụ async chạy sau.
