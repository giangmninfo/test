Classes and Objects in JavaScript — Lớp & đối tượng

Cấp độ: Cơ bản Cập nhật: 30/06/2026 498K lượt đọc

Class (lớp) là "khuôn" mô tả một loại đối tượng — gồm thuộc tính và method. Object (đối tượng) là một thực thể cụ thể được tạo từ class bằng từ khoá new. Cú pháp class (ES6) giúp viết OOP gọn gàng, dễ đọc.

Ghi nhớ: tên class viết hoa chữ cái đầu; constructor() chạy khi tạo object. Bên dưới class vẫn là prototype. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Tóm tắt

Class là khuôn mô tả thuộc tính & method; object là thực thể tạo từ class bằng new. Class gồm constructor, method, class field, getter/setter, thành phần static và trường riêng tư #. Có thể viết dưới dạng khai báo hoặc class expression.
