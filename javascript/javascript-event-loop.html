Event Loop in JavaScript — Vòng lặp sự kiện

Cấp độ: Trung cấp Cập nhật: 30/06/2026 421K lượt đọc

Event loop (vòng lặp sự kiện) là cơ chế giúp JavaScript — vốn đơn luồng — vẫn xử lý được nhiều tác vụ bất đồng bộ mà không bị "đóng băng". Nó liên tục kiểm tra call stack và lấy các callback đang chờ từ các hàng đợi ra chạy.

Nguyên tắc vàng: code đồng bộ chạy trước (trên call stack); khi stack rỗng, event loop chạy hết microtask (Promise) rồi mới lấy một macrotask (setTimeout). Ví dụ dưới chỉ dùng JavaScript, in ra console.

JavaScript là đơn luồng

Chỉ có một call stack — mỗi lúc chỉ chạy một việc. Tác vụ chờ được "giao" cho Web APIs của trình duyệt xử lý song song, rồi callback quay lại qua hàng đợi.

Các thành phần của Event Loop

Cơ chế hoạt động (từng bước)

Một vòng của event loop diễn ra theo trình tự sau:

  1. Chạy code đồng bộ: mọi lời gọi hàm được đẩy lên Call Stack và thực thi lần lượt (vào sau, ra trước — LIFO).
  2. Giao tác vụ chờ: khi gặp tác vụ bất đồng bộ (setTimeout, fetch, sự kiện DOM…), JavaScript chuyển nó cho Web APIs của trình duyệt xử lý song song, rồi tiếp tục chạy code đồng bộ (không chờ).
  3. Xếp callback vào hàng đợi: khi Web API hoàn tất, callback được đưa vào Macrotask Queue (setTimeout, I/O, sự kiện) hoặc Microtask Queue (Promise.then, queueMicrotask).
  4. Event loop kiểm tra: nếu Call Stack rỗng, event loop lấy callback từ hàng đợi đẩy lên stack để chạy.
  5. Ưu tiên microtask: mỗi lần stack rỗng, chạy hết Microtask Queue trước; sau đó lấy một macrotask, chạy xong lại quay về xử lý hết microtask — cứ thế lặp lại.
Ví dụ dễ hình dung: hãy nghĩ event loop như một nhân viên phục vụ. Bếp (Call Stack) chỉ nấu một món tại một thời điểm. Món cần chờ lâu (Web APIs) được để riêng; khi xong, phiếu gọi được xếp vào hàng. Nhân viên luôn ưu tiên xử lý hết các phiếu "gấp" (microtask) rồi mới lấy một phiếu thường (macrotask) tiếp theo.

Thực hành tốt

  • Đừng chặn call stack bằng vòng lặp/tính toán nặng — trang sẽ "đơ".
  • Hiểu rằng Promise (microtask) luôn chạy trước setTimeout (macrotask).
  • setTimeout(fn, 0) để "hoãn" việc tới sau khi code đồng bộ xong.
  • Chia tác vụ nặng thành nhiều phần nhỏ để không làm nghẽn event loop.

Tóm tắt

Event loop giúp JavaScript đơn luồng xử lý bất đồng bộ: call stack chạy code đồng bộ; tác vụ chờ giao cho Web APIs; callback quay về qua task queue (macrotask: setTimeout) hoặc microtask queue (Promise). Khi stack rỗng, event loop chạy hết microtask rồi mới lấy một macrotask — nên Promise luôn chạy trước setTimeout.

Bước tiếp theo: Tiếp theo trong nhóm Asynchronous JavaScript: async/await, Fetch API… (sắp ra mắt). Ôn lại JavaScript Promises.
