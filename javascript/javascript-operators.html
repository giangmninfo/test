JavaScript Operators — Toán tử trong JavaScript

Cấp độ: Cơ bản Cập nhật: 23/06/2026 476K lượt đọc

Toán tử (operator) là các ký hiệu thực hiện thao tác trên giá trị/biến (gọi là toán hạng) — cộng trừ, so sánh, gán, logic… JavaScript có nhiều nhóm toán tử phong phú.

Toán hạng & toán tử: trong 5 + 3, 5 và 3 là toán hạng, + là toán tử. Các ví dụ dưới chỉ dùng JavaScript, in kết quả ra console.

Các nhóm toán tử

Toán tử số học (Arithmetic)

+ - * / % (chia lấy dư) và ** (luỹ thừa):

Toán tử gán (Assignment)

= và các dạng rút gọn += -= *= /= %=:

Toán tử so sánh (Comparison)

== so sánh giá trị (có ép kiểu); === so sánh cả giá trị lẫn kiểu (nên ưu tiên). !=/!== là phủ định:

Toán tử quan hệ (Relational)

< > <= >=, cùng in và instanceof:

Toán tử logic (Logical)

&& (VÀ), || (HOẶC), ! (PHỦ ĐỊNH):

Toán tử ba ngôi (Ternary)

Viết gọn if/else: điều_kiện ? giá_trị_đúng : giá_trị_sai:

Toán tử một ngôi (Unary)

typeof, tăng/giảm ++/--, đảo dấu -, phủ định !:

Toán tử bit (Bitwise)

Thao tác trên bit nhị phân: & | ^ ~ << >>:

Độ ưu tiên (Operator Precedence)

Toán tử có thứ tự ưu tiên: *, / trước +, -; dùng ngoặc () để ép thứ tự cho rõ ràng:

Thực hành tốt

  • Ưu tiên ===/!== (so sánh nghiêm ngặt) thay vì ==/!=.
  • Dùng ngoặc () để làm rõ thứ tự tính toán.
  • Dùng toán tử ba ngôi cho điều kiện ngắn; if/else cho logic phức tạp.
  • Cẩn thận + giữa số & chuỗi (dễ thành nối chuỗi).

Tóm tắt

JavaScript có nhiều nhóm toán tử: số học (+ - * / % **), gán (= += …), so sánh (== === != !==), quan hệ (< > in instanceof), logic (&& || !), ba ngôi (? :), một ngôi (typeof ++ --) và bit (& | ^ ~ << >>). Ưu tiên === và dùng () cho rõ thứ tự.

Bước tiếp theo: Tiếp theo: Conditionals (if/else, switch), Loops… (sắp ra mắt). Ôn lại Variables & Datatypes.
