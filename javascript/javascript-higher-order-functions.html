JavaScript Higher-Order Functions — Hàm bậc cao

Cấp độ: Nâng cao Cập nhật: 06/07/2026 473K lượt đọc

Higher-order function (hàm bậc cao) là hàm nhận một hàm khác làm đối số, hoặc trả về một hàm (hoặc cả hai). Đây là nền tảng của lập trình hàm (functional) trong JavaScript — giúp code ngắn gọn, dễ tái sử dụng và dễ đọc.

Vì sao có được: trong JavaScript, hàm là giá trị — có thể gán vào biến, truyền đi, trả về. Các HOF quen thuộc nhất: map, filter, reduce, forEach, sort. Ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Ưu tiên map/filter/reduce thay vòng lặp thủ công khi phù hợp.
  • Dùng arrow function cho callback ngắn gọn.

Tóm tắt

Higher-order function là hàm nhận hàm khác làm đối số hoặc trả về một hàm — nhờ hàm là giá trị trong JavaScript. Các HOF phổ biến: map (biến đổi), filter (lọc), reduce (gộp), forEach, some/every. HOF có thể trả về hàm để tạo hàm chuyên biệt, và nối chuỗi (filter→map→reduce) để xử lý dữ liệu gọn, dễ đọc.

Bước tiếp theo: Tiếp theo trong nhóm Advanced Topics: this keyword, Prototype, Currying… (sắp ra mắt). Ôn lại Closures.
