JavaScript Function Expression — Biểu thức hàm

Cấp độ: Cơ bản Cập nhật: 23/06/2026 356K lượt đọc

Function expression (biểu thức hàm) là khi ta gán một hàm vào biến. Khác với function declaration, hàm ở đây được coi như một giá trị — có thể gán, truyền vào hàm khác, hoặc trả về từ hàm khác.

Điểm mấu chốt: function expression không được hoisting — phải định nghĩa trước khi gọi. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Định nghĩa function expression trước khi dùng (không có hoisting).
  • Dùng const để hàm không bị gán lại ngoài ý muốn.
  • Đặt tên cho biểu thức hàm khi cần đệ quy hoặc gỡ lỗi dễ hơn.
  • Ưu tiên arrow function cho callback ngắn; function khi cần this/arguments.

Tóm tắt

Function expression gán một hàm vào biến, coi hàm như giá trị — có thể truyền, trả về, gán theo điều kiện. Khác function declaration ở chỗ không được hoisting (phải định nghĩa trước khi gọi). Có thể ẩn danh hoặc có tên; arrow function cũng là một dạng expression; bọc trong () và gọi ngay tạo IIFE.
