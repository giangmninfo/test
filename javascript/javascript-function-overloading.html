Function Overloading in JavaScript — Nạp chồng hàm

Cấp độ: Cơ bản Cập nhật: 23/06/2026 289K lượt đọc

Nạp chồng hàm (function overloading) là việc có nhiều hàm cùng tên nhưng khác nhau về số lượng/kiểu tham số (như trong Java, C++). JavaScript không hỗ trợ điều này một cách trực tiếp — nhưng ta có thể mô phỏng bằng nhiều kỹ thuật.

Quan trọng: nếu khai báo hai hàm cùng tên, hàm sau sẽ ghi đè hàm trước. Để "nạp chồng", ta dùng một hàm duy nhất và xử lý đối số bên trong. Ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Dùng một hàm với default/rest thay vì nhiều hàm cùng tên.
  • Khi nhiều tham số tuỳ chọn, ưu tiên options object cho rõ ràng.
  • Kiểm tra kiểu cẩn thận (typeof, Array.isArray) trước khi xử lý.
  • Đặt nhánh xử lý gọn gàng; cân nhắc tách hàm con nếu logic phức tạp.

Tóm tắt

JavaScript không hỗ trợ nạp chồng hàm trực tiếp (hàm cùng tên định nghĩa sau ghi đè hàm trước). Ta mô phỏng bằng cách dùng một hàm và xử lý đối số bên trong: kiểm tra arguments.length, kiểm tra typeof, dùng tham số mặc định, rest parameters hoặc options object.

Bước tiếp theo: Tiếp theo trong nhóm Function & Object: Arrow Functions, Closures, JavaScript Objects… (sắp ra mắt). Ôn lại Function Expression.
