JavaScript Custom Events — Sự kiện tuỳ chỉnh

Cấp độ: Nâng cao Cập nhật: 30/06/2026 228K lượt đọc

Ngoài các sự kiện dựng sẵn (click, input…), JavaScript cho phép bạn tự tạo sự kiện riêng gọi là custom event. Bạn định nghĩa tên sự kiện, đính kèm dữ liệu, rồi kích hoạt (dispatch) để phần khác của ứng dụng lắng nghe (listen) và phản ứng.

Ba bước cốt lõi: tạo sự kiện với new CustomEvent(name, { detail }), lắng nghe bằng addEventListener(name, handler), và phát ra bằng element.dispatchEvent(event). Ví dụ dưới dùng HTML + CSS + JS và hiển thị kết quả trực tiếp.

Vì sao cần custom event?

  • Tách rời (decoupling): một phần "thông báo", phần khác "phản ứng" mà không gọi trực tiếp nhau.
  • Giao tiếp giữa component: truyền dữ liệu qua detail giữa các thành phần độc lập.
  • Mở rộng dễ: nhiều listener cùng phản ứng với một sự kiện.

Thực hành tốt

  • Đặt tên sự kiện rõ nghĩa (vd "itemAdded", "userLoggedIn").
  • Truyền dữ liệu qua detail; đọc bằng e.detail ở listener.
  • Dùng { bubbles: true } khi cần sự kiện lan lên cha.
  • Gỡ listener khi không cần để tránh rò rỉ bộ nhớ (giữ cùng tham chiếu hàm).

Tóm tắt

Custom event cho phép tự định nghĩa sự kiện riêng: tạo bằng new CustomEvent(name, { detail, bubbles }), lắng nghe bằng addEventListener, phát ra bằng dispatchEvent. Dữ liệu đính kèm đọc qua e.detail; đặt bubbles: true để sự kiện nổi bọt lên cha. Custom event giúp tách rời và giao tiếp giữa các thành phần; nhớ gỡ listener khi không dùng.

Bước tiếp theo: Tiếp theo trong nhóm DOM: DOM Events nâng cao, Event Delegation, Manipulating Elements… (sắp ra mắt). Ôn lại Selecting DOM Elements.
