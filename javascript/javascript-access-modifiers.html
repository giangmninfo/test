Access Modifiers in JavaScript — Bộ điều chỉnh truy cập

Cấp độ: Trung cấp Cập nhật: 30/06/2026 256K lượt đọc

Access modifier (bộ điều chỉnh truy cập) quyết định thành phần của class được truy cập từ đâu. Khác Java/C++ (có public/private/protected), JavaScript chỉ có public (mặc định) và private thật sự qua tiền tố #; protected chỉ là quy ước dùng dấu _.

Ghi nhớ: # là riêng tư thật (engine chặn truy cập ngoài class); còn _ chỉ "nhắc" lập trình viên đừng đụng vào — vẫn truy cập được. Các ví dụ dưới chỉ dùng JavaScript, in ra console.

Thực hành tốt

  • Dùng # cho dữ liệu cần ẩn thật sự (mật khẩu, số dư…).
  • Cho truy cập có kiểm soát qua getter/setter thay vì để public.
  • Dùng _ chỉ để "gợi ý nội bộ"; đừng coi đó là bảo mật.
  • Giữ public API gọn — phơi bày càng ít càng dễ bảo trì.

Tóm tắt

JavaScript có public (mặc định) và private thật sự bằng tiền tố # (thuộc tính & method); protected chỉ là quy ước với dấu _ (vẫn truy cập được). Kết hợp # với getter/setter để truy cập có kiểm soát; có thể dùng static # hoặc closure (cách cũ) để giữ dữ liệu riêng.

Bước tiếp theo: Tiếp theo trong nhóm OOP: Inheritance, Encapsulation, Polymorphism… (sắp ra mắt). Ôn lại Classes & Objects.
