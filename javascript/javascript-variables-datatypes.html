Variables & Datatypes in JavaScript — Biến & kiểu dữ liệu

Cấp độ: Cơ bản Cập nhật: 23/06/2026 388K lượt đọc

Biến (variable) là "vùng nhớ có tên" để lưu trữ dữ liệu. Trong JavaScript, biến được khai báo bằng var, let hoặc const và có thể chứa nhiều kiểu dữ liệu khác nhau.

Ghi nhớ: Ưu tiên let (thay đổi được) & const (hằng số); hạn chế var. Các ví dụ dưới chỉ dùng JavaScript, kết quả in ra console.

Quy tắc đặt tên biến

  • Bắt đầu bằng chữ cái, _ hoặc $ (không bắt đầu bằng số).
  • Phân biệt hoa/thường: ten khác Ten.
  • Không trùng từ khoá; nên dùng camelCase (vd tenNguoiDung).
  • Đặt tên rõ nghĩa để code dễ đọc.

Các kiểu dữ liệu

JavaScript có hai nhóm: nguyên thuỷ (primitive) — number, string, boolean, null, undefined, bigint, symbol; và tham chiếu (non-primitive) — object (gồm array, function, Date…).

Tóm tắt

Biến lưu dữ liệu, khai báo bằng let/const (ưu tiên) hoặc var. JavaScript có kiểu nguyên thuỷ (number, string, boolean, null, undefined, bigint, symbol) và object (tham chiếu). Kiểm tra kiểu bằng typeof, chuyển đổi bằng Number()/String()…; JS là ngôn ngữ kiểu động.
