JavaScript HTML DOM — Thao tác trang HTML bằng DOM

Cấp độ: Trung cấp Cập nhật: 06/07/2026 641K lượt đọc

HTML DOM là mô hình chuẩn để JavaScript truy cập và thay đổi mọi phần tử của một trang HTML. Khi trang được tải, trình duyệt dựng một cây đối tượng (DOM); qua đối tượng document, JavaScript có thể đọc/đổi nội dung, thuộc tính, kiểu dáng và phản ứng với sự kiện — làm trang web trở nên động.

Nói cách khác: HTML DOM định nghĩa các phần tử là đối tượng, cùng thuộc tính, method và sự kiện để thao tác chúng. Các ví dụ dưới dùng HTML + CSS + JS và hiển thị kết quả trực tiếp.

Với HTML DOM, JavaScript có thể…

  • Thay đổi nội dung của mọi phần tử HTML.
  • Thay đổi thuộc tính (src, href, value…) và kiểu dáng CSS.
  • Thêm / xoá phần tử & thuộc tính.
  • Phản ứng với sự kiện của người dùng (click, gõ phím…).

Tóm tắt

HTML DOM cho phép JavaScript truy cập & thay đổi trang HTML qua document: đổi nội dung (innerHTML/textContent), thuộc tính (setAttribute), CSS (style/classList), thêm/xoá phần tử (createElement/remove) và phản ứng sự kiện (addEventListener). Có thể điều hướng cây DOM qua parentNode/children/nextElementSibling.
